# 光域台球网页版本

部署到 GitHub Pages 的静态八球／九球游戏，支持挑战电脑和同屏双人。

## 运行

在本目录执行 `python -m http.server 8765`，浏览器打开 `http://127.0.0.1:8765/`。网站资源全部使用相对路径，可放在 GitHub Pages 仓库的子目录。

## 操作

- 在球台上拖动瞄准，或横向拖动右侧刻度尺精调；刻度尺每拖动 100 像素约调 1°，桌面左右键每次微调 0.01°。
- 向下拖动右侧球杆，松手击球；也可点“击球”或按空格。右侧球杆可用上下键调节力度。
- 辅助线从母球连到首碰点，显示母球与目标球碰后的分离实线；目标球到袋口的延伸虚线已去除。碰库后不继续画线；首碰球不合法时显示红色。首碰辅助线使用与力度无关的几何路径，蓄力期间保持稳定；轻力度也可先描出远处线路。
- 拖动白色击球点设置左右旋和高低杆；犯规后拖动白球摆放，点击“确认白球位置”。击球前可点“重新摆放白球”。
- 八球清空己方球后，合法打进 8 号球即可获胜，无需指定袋口。
- 按 `F` 切换全屏。
- 进入球场后尝试启动 [Enzalla《Lullaby》](https://soundcloud.com/enzalla/lullaby) 的官方 SoundCloud 播放器，音量设为 35%，播完后循环。顶部音乐键开关；浏览器阻止自动播放时显示播放器供手动启动。网络不可用会显示提示并保留本机音频导入。歌曲不重新上传到 GitHub，使用艺人公开提供的嵌入播放。斯诺克视频的官方配乐详情已核实艺人为 Enzalla，之前的 528Hz Studio 同名候选不准确。
- 球碰球与出杆使用从真实台球桌录音中剪辑的短促碰撞声，按力度调音量并滤去刺耳高频；碰库和落袋保留较柔和的独立音效。原始录音 [Pool Sounds.ogg](https://commons.wikimedia.org/wiki/File:Pool_Sounds.ogg) 由 Dsw4 录制并释放至公有领域。
- 竖屏手机自动以横向球台呈现；把设备横过来可正常观看。进入全屏时，浏览器允许的话会尝试锁定横屏。

## 规则与物理

桌面内沿 2540×1270 毫米，物理球径 57.15 毫米。六个袋口在上一版约 96.4 毫米基础上再加宽 2% 至约 98.3 毫米；球的画面直径增大 3.5%，碰撞半径保持不变。这是本作按参考图调整的试玩参数，并非所有赛事球台的统一标准。袋口由蓝色台呢包覆的实体胶库构成约 38 毫米深的袋道，中袋库嘴收进边库内，与库鼻齐平，不再向台面凸出；袋道及实体库嘴统一深蓝色，去掉浅蓝亮边；球越过入口后仍会运动、触碰袋道内库，到袋道后端才落袋。袋道画面、库嘴碰撞和落袋判定共用世界坐标。袋口无网纹，入袋光圈与粒子固定在最终判定袋口的中心发出；越界但未通过袋道的球不会误记进袋。蓝色台呢加上 S686 标记，球面色带和球号随滚动一起旋转，球号转到背面时会自然消失。

球的平移速度、前后旋和侧旋分别保存。默认 56% 力度的普通出杆约为 61 英寸／秒；100% 普通击球约为 133 英寸／秒，满力开球约为 547–557 英寸／秒；60% 以上逐渐增幅，低力度响应保持不变。每局使用新的随机种子重新排列球号（八球固定 8 号居中且底角一全色一花色，九球固定 1 号在前、9 号居中），球阵位置有微小扰动，开球力度也有小范围随机变化，瞄准方向保持不变。高速球每帧增加子步碰撞检查，降低穿球与穿袋道的风险。满力出杆的前后旋和侧旋系数高于中等力度，击球点在出杆后自动回到中杆。台呢滑动摩擦系数取 0.20；按实心球转动惯量 `I=2/5 mr²`，接触点滑动速度以 `3.5 μs g` 收敛，滑动结束时再进入纯滚动。纯滚动阻力系数取 0.012，减速度约 4.63 英寸／秒²，按 `v(t)=max(0,v₀−μrgt)` 逐渐停球，不再使用低速指数拖尾。低杆碰球后保留回旋并逐渐拉回白球，高杆保留前旋并逐渐带白球向前。无侧旋球出库后以短暂滑动继续损失速度，并保持直线；顺塞与反塞仍影响出库切向速度，碰库前后的总动能受限制。碰库旋转处理是二维近似，并非 Unity PhysX 原始参数。

画布使用设备像素密度绘制，比例限定在 1.75–2.4 倍；高像素密度设备的内部画布约 3360×1896 像素。球面光照系数与台呢纤维预计算；球面纹理只在可见角度变化达到阈值时重绘，球号贴图预先缓存，运动拖影不使用实时模糊。拖动瞄准时，同一显示帧内的多次指针更新合并重绘，球路计算跳过静止球之间无意义的碰撞检测。球面采用参考图的深色树脂、高光与黑边米白色异形号码标，号码和色带随球一起滚动。实际平板帧率仍取决于设备与浏览器。

包含八球分组、首球合法性、白球落袋、无碰库犯规、自由摆球及胜负判定；清台后合法打进 8 号球即可获胜，不要求叫袋。九球要求先碰最小号球，合法打进 9 号球获胜。开球和推杆流程为适合网页双人／人机对战的简化规则。

电脑对手分为入门、标准、大师三级。先筛除被挡的球路，再用游戏同一套碰撞与滑滚摩擦试算，优先选择合法进袋且不白球落袋的方案；无进攻线路时评估对手的可进球路径、首碰遮挡和白球落点，选择薄球防守或一库／两库解球，所有方案都使用实际物理试算确认合法性、碰库及白球不落袋。思路在屏幕中心显示 2.5 秒，电脑辅助线隐藏。试算与真实音效和进袋反馈隔离。

原 Android 游戏是 Unity IL2CPP 程序。恢复资料含类结构和不完整伪代码，不含可直接移植的原始游戏方法体或 PhysX 实现。本项目用独立 Canvas 物理实现复现核心玩法与操作，并未宣称与原游戏逐帧一致。页面没有公开原 APK、Unity 素材或反编译文件。
