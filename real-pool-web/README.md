# 光域台球网页版本

部署到 GitHub Pages 的静态八球／九球游戏，支持挑战电脑和同屏双人。

## 运行

在本目录执行 `python -m http.server 8765`，浏览器打开 `http://127.0.0.1:8765/`。网站资源全部使用相对路径，可放在 GitHub Pages 仓库的子目录。

## 操作

- 在球台上拖动瞄准，或横向拖动右侧刻度尺精调；刻度尺每拖动 100 像素约调 1°，桌面左右键每次微调 0.01°。
- 向下拖动右侧球杆，松手击球；也可点“击球”或按空格。右侧球杆可用上下键调节力度。
- 辅助线从母球连到首碰点，显示母球与目标球碰后的分离实线；目标球到袋口的延伸虚线已去除。碰库后不继续画线；首碰球不合法时显示红色。首碰辅助线使用与力度无关的几何路径，蓄力期间保持稳定；轻力度也可先描出远处线路。
- 拖动白色击球点设置左右旋和高低杆；犯规后拖动白球摆放，点击“确认白球位置”。击球前可点“重新摆放白球”。
- 八球清空己方球后，合法打进 8 号球即可获胜，无需指定袋口。
- 按 `F` 切换全屏。
- 顶部“导入斯诺克小曲”可选择本机音频，导入后在当前浏览器循环播放并可开关；文件不会上传。旧版不准确的自编 Lullaby 风格循环已移除。曲目检索到 [528Hz Studio《lullaby (斯诺克小曲)》](https://play.anghami.com/song/1209678064)，正式版在取得可公开使用的录音或用户提供授权文件前不随站点打包该曲。
- 球碰球与出杆使用从真实台球桌录音中剪辑的短促碰撞声，按力度调音量并滤去刺耳高频；碰库和落袋保留较柔和的独立音效。原始录音 [Pool Sounds.ogg](https://commons.wikimedia.org/wiki/File:Pool_Sounds.ogg) 由 Dsw4 录制并释放至公有领域。
- 竖屏手机自动以横向球台呈现；把设备横过来可正常观看。进入全屏时，浏览器允许的话会尝试锁定横屏。

## 规则与物理

桌面内沿 2540×1270 毫米，物理球径 57.15 毫米。六个袋口由上一版约 94.5 毫米再加宽 2% 至约 96.4 毫米；球的画面直径增大 3.5%，碰撞半径保持不变。这是本作按参考图调整的试玩参数，并非所有赛事球台的统一标准。袋口由两侧短直库构成约 38 毫米深的袋道；球越过入口后仍会运动、触碰袋道内库，到袋道后端才落袋。袋道画面、库嘴碰撞和落袋判定共用世界坐标。袋口无网纹，入袋光圈与粒子固定在最终判定袋口的中心发出；越界但未通过袋道的球不会误记进袋。蓝色台呢加上 S686 标记，球面色带和球号随滚动一起旋转，球号转到背面时会自然消失。

球的平移速度、前后旋和侧旋分别保存。默认 56% 力度的普通出杆约为 61 英寸／秒；满力开球约为 390–398 英寸／秒。每局使用新的随机种子重新排列球号（八球固定 8 号居中且底角一全色一花色，九球固定 1 号在前、9 号居中），球阵位置有微小扰动，开球力度也有小范围随机变化，瞄准方向保持不变。高速球每帧增加子步碰撞检查，降低穿球与穿袋道的风险。满力出杆的前后旋和侧旋系数高于中等力度，击球点在出杆后自动回到中杆。台呢滑动摩擦系数取 0.20；按实心球转动惯量 `I=2/5 mr²`，接触点滑动速度以 `3.5 μs g` 收敛，滑动结束时再进入纯滚动。纯滚动阻力系数取 0.012，减速度约 4.63 英寸／秒²，按 `v(t)=max(0,v₀−μrgt)` 逐渐停球，不再使用低速指数拖尾。低杆碰球后保留回旋并逐渐拉回白球，高杆保留前旋并逐渐带白球向前。无侧旋球出库后以短暂滑动继续损失速度，并保持直线；顺塞与反塞仍影响出库切向速度，碰库前后的总动能受限制。碰库旋转处理是二维近似，并非 Unity PhysX 原始参数。

画布使用设备像素密度绘制，比例限定在 1.75–2.4 倍；高像素密度设备的内部画布约 3360×1896 像素。球面光照系数与台呢纤维预计算；球面纹理只在可见角度变化达到阈值时重绘，球号贴图预先缓存，运动拖影不使用实时模糊。拖动瞄准时，同一显示帧内的多次指针更新合并重绘，球路计算跳过静止球之间无意义的碰撞检测。球面采用参考图的深色树脂、高光与黑边米白色异形号码标，号码和色带随球一起滚动。实际平板帧率仍取决于设备与浏览器。

包含八球分组、首球合法性、白球落袋、无碰库犯规、自由摆球及胜负判定；清台后合法打进 8 号球即可获胜，不要求叫袋。九球要求先碰最小号球，合法打进 9 号球获胜。开球和推杆流程为适合网页双人／人机对战的简化规则。

电脑对手分为入门、标准、大师三级，分别调整候选球路、瞄准误差和击球力度误差。

原 Android 游戏是 Unity IL2CPP 程序。恢复资料含类结构和不完整伪代码，不含可直接移植的原始游戏方法体或 PhysX 实现。本项目用独立 Canvas 物理实现复现核心玩法与操作，并未宣称与原游戏逐帧一致。页面没有公开原 APK、Unity 素材或反编译文件。

物理参数参考：[WPA 球台设备规范](https://www.wpapool.com/wp-content/uploads/2024/01/RECOMMENDED-EQUIPMENT-SPECIFICATIONS.pdf)、[Pooltool 滑动与滚动公式](https://ekiefl.github.io/2020/12/20/pooltool-alg/)、[台呢滚动阻力与库边损耗计算](https://drdavepoolinfo.com/technical_proofs/new/TP_B-6.pdf)、[球碰库与侧旋研究](https://doi.org/10.1243/09544062JMES1964)。资料提供校准范围；本作仍需按设备和实际试玩继续调校。
