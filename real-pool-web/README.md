# 真实台球网页版本

可直接部署到 GitHub Pages 的静态八球／九球游戏，支持挑战电脑和同屏双人。

## 运行

在本目录执行 `python -m http.server 8765`，浏览器打开 `http://127.0.0.1:8765/`。网站资源全部使用相对路径，可放在 GitHub Pages 仓库的子目录。

## 操作

- 在球台上拖动瞄准；桌面可用左右键微调。
- 向下拖动右侧球杆，松手击球；也可点“击球”或按空格。右侧球杆可用上下键调节力度。
- 白色辅助线显示母球和目标球的预计运动方向；首碰球不合法时显示红色。
- 拖动白色击球点设置左右旋和高低杆；犯规后拖动白球摆放。
- 八球清空己方球后，点击袋口指定 8 号球落袋。
- 按 `F` 切换全屏。

## 规则与物理

桌面内沿 100×50 英寸，球径 2.25 英寸。按试玩反馈，角袋口增至 5 英寸，中袋口增至 5.7 英寸；这是本游戏的手感参数，不是赛事器材标准。袋口间隙、球与库边碰撞以及落袋判定共用同一套世界坐标，不只调整视觉尺寸。中袋采用较浅的落袋阈值及较轻的袋角碰撞，方便正面和小角度进袋。球的滑动阻力在碰撞后逐渐过渡到滚动阻力，球面纹理按行进距离转动。

包含八球分组、首球合法性、指定 8 号球袋口、白球落袋、无碰库犯规、自由摆球及胜负判定；九球要求先碰最小号球，合法打进 9 号球获胜。开球、叫袋和推杆流程为适合网页双人／人机对战的简化规则。

电脑对手分为入门、标准、大师三级，分别调整候选球路、瞄准误差和击球力度误差。

原 Android 游戏是 Unity IL2CPP 程序。恢复资料含类结构和不完整伪代码，不含可直接移植的原始游戏方法体或 PhysX 实现。本项目用独立 Canvas 物理实现复现核心玩法与操作，并未宣称与原游戏逐帧一致。页面没有公开原 APK、Unity 素材或反编译文件。
