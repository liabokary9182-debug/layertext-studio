# 光域台球网页版本

部署到 GitHub Pages 的静态八球／九球游戏，支持挑战电脑和同屏双人。

## 运行

在本目录执行 `python -m http.server 8765`，浏览器打开 `http://127.0.0.1:8765/`。网站资源全部使用相对路径，可放在 GitHub Pages 仓库的子目录。

## 操作

- 在球台上拖动瞄准，或横向拖动右侧刻度尺精调；刻度尺每拖动 40 像素约调 1°，桌面左右键每次微调 0.05°。
- 向下拖动右侧球杆，松手击球；也可点“击球”或按空格。右侧球杆可用上下键调节力度。
- 辅助线从母球连到首碰点，显示母球与目标球碰后的分离实线；目标球到袋口的延伸虚线已去除。碰库后不继续画线；首碰球不合法时显示红色。
- 拖动白色击球点设置左右旋和高低杆；犯规后拖动白球摆放，点击“确认白球位置”。击球前可点“重新摆放白球”。
- 八球清空己方球后，点击袋口指定 8 号球落袋。
- 按 `F` 切换全屏。
- 点击顶部“Lullaby”按钮切换原创的摇篮曲风格电子循环；首次点击“进入球场”后自动播放。网页需要一次点击来解锁浏览器音频。
- 出杆、球碰球、碰库、落袋分别有独立的合成音效；这版提高了音量并为同时碰撞加入动态压缩，关闭背景音乐不会关闭击球反馈。
- 竖屏手机自动以横向球台呈现；把设备横过来可正常观看。进入全屏时，浏览器允许的话会尝试锁定横屏。

## 规则与物理

桌面内沿 2540×1270 毫米，球径 57.15 毫米。六个袋口由上一版约 88.6 毫米加宽 2% 至约 90.4 毫米，入口宽度约为球径的 1.58 倍。这是本作的试玩参数，并非所有赛事球台的统一标准。袋口由两侧短直库构成约 38 毫米深的袋道；球越过入口后仍会运动、触碰袋道内库，到袋道后端才落袋。袋道画面、库嘴碰撞和落袋判定共用世界坐标。袋口无网纹，入袋光圈与粒子从球实际落入袋道的位置发出。蓝色台呢加上 S686 标记，球面色带和球号随滚动一起旋转，球号转到背面时会自然消失。

球的平移速度、前后旋和侧旋分别保存。默认 56% 力度的普通出杆约为 61 英寸／秒，开球约为 121 英寸／秒。台呢滑动摩擦系数取 0.20；按实心球转动惯量 `I=2/5 mr²`，接触点滑动速度以 `3.5 μs g` 收敛，滑动结束时再进入纯滚动。纯滚动阻力系数取 0.012，减速度约 4.63 英寸／秒²，按 `v(t)=max(0,v₀−μrgt)` 逐渐停球，不再使用低速指数拖尾。低杆碰球后保留回旋并逐渐拉回白球，高杆保留前旋并逐渐带白球向前。无侧旋球出库后以短暂滑动继续损失速度，并保持直线；顺塞与反塞仍影响出库切向速度，碰库前后的总动能受限制。碰库旋转处理是二维近似，并非 Unity PhysX 原始参数。

画布使用设备像素密度绘制，比例限定在 1.75–2.4 倍；高像素密度设备的内部画布约 3360×1896 像素。球面光照系数与台呢纤维预计算；球面纹理只在可见角度变化达到阈值时重绘，球号贴图预先缓存，运动拖影不使用实时模糊。拖动瞄准时，同一显示帧内的多次指针更新合并重绘，球路计算跳过静止球之间无意义的碰撞检测。纯色球的号码底色随球色变化，花色球保留浅色号码底。实际平板帧率仍取决于设备与浏览器。

包含八球分组、首球合法性、指定 8 号球袋口、白球落袋、无碰库犯规、自由摆球及胜负判定；九球要求先碰最小号球，合法打进 9 号球获胜。开球、叫袋和推杆流程为适合网页双人／人机对战的简化规则。

电脑对手分为入门、标准、大师三级，分别调整候选球路、瞄准误差和击球力度误差。

原 Android 游戏是 Unity IL2CPP 程序。恢复资料含类结构和不完整伪代码，不含可直接移植的原始游戏方法体或 PhysX 实现。本项目用独立 Canvas 物理实现复现核心玩法与操作，并未宣称与原游戏逐帧一致。页面没有公开原 APK、Unity 素材或反编译文件。

物理参数参考：[WPA 球台设备规范](https://www.wpapool.com/wp-content/uploads/2024/01/RECOMMENDED-EQUIPMENT-SPECIFICATIONS.pdf)、[Pooltool 滑动与滚动公式](https://ekiefl.github.io/2020/12/20/pooltool-alg/)、[台呢滚动阻力与库边损耗计算](https://drdavepoolinfo.com/technical_proofs/new/TP_B-6.pdf)、[球碰库与侧旋研究](https://doi.org/10.1243/09544062JMES1964)。资料提供校准范围；本作仍需按设备和实际试玩继续调校。
